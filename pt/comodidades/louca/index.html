Lava-louças

Como usar

  • A máquina utiliza produtos próprios para lava-louças. Não use detergente comum nem sabão de lavar roupas.
  • O equipamento fica desligado para evitar o uso de produtos inadequados. Entre em contato para que eu o ative remotamente.
  • Utilize uma pastilha para lava-louças e líquido secante/abrilhantador. Os exemplos das fotos são FINISH TABS e CIF Secante.
