Banheiro

Registro geral água não mexer. Rotacionar para o lado direito para acionar água quente ( aguardar 10 segundos para que a água aqueça). Rotacionar para o lado esquerdo para acionar a água da duchinha. Rotacionar para o lado esquerdo para acionar água fria. Banheiro Levantar a alavanca do lado esquerdo para água quente Levantar a alavanca do lado esquerdo para água fria
