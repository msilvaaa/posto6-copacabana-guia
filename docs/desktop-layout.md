# Consistent desktop, phone and tablet layout

The guest guide uses a centered content area capped at **1440 × 900 CSS pixels**. Wider TV and desktop viewports add outer margins instead of spreading the content or increasing font sizes. Smaller desktop windows use the available width and height; short cover windows scroll inside the content area.

`desktop-layout.css` contains the reference dimensions, toolbar anchors, fixed cover type sizes, menu button diameter and arrow gaps. Do not use a CSS transform or browser zoom to scale the page: normal CSS layout preserves text rendering, dialogs and pointer coordinates.

The initial head script applies `data-desktop-frame` before the first paint. `site.js` maintains it on resize. Activation requires a viewport wider than 1100px, including wide tablets and TVs with remote controls. Screens up to 1100px use `data-fluid-frame` and the rules in `responsive-layout.css`: an 840px maximum content width, stacked photo/content panels, readable 16px body copy, 44px navigation targets and room for the title/WhatsApp row. Archived `/preview-*` mockups opt out.

Home, language flags and previous/next controls stay centered within the appropriate half-width content panel or 30% cover menu. Arrow-to-button gaps are 1cm on the reference layout; the cover gap reduces only when a narrower desktop cannot fit the full gap. The WhatsApp inset is measured from the content area's right edge, not from the browser's outer margin. On desktop the cover contact is 16px from the frame edge, with its base aligned to the menu divider and its gentle floating motion restored. Elsewhere it stays on the title row; the compact cover keeps its dedicated clock/contact row.

Self-hosted **Guide Sans** (Arimo subset) and **Guide Serif** (Gelasio subset) prevent system-font substitutions. They are metrically compatible alternatives to the original Arial and Georgia families. The original SVG title artwork, handwritten signatures and Courgette font are preserved. Font licenses and source links are in `assets/fonts/desktop-ui/`. The same self-hosted families apply to all screen sizes to maintain the visual identity across operating systems.

Validation compares normalized element geometry and computed typography at 1440×900, 1920×1080, 2560×1440 and 3840×2160. Include a coarse-pointer/no-touch TV profile, a high-DPI desktop profile, smaller windows, and phone/tablet checks at 320, 390, 768, 1024 and 1366 CSS pixels when changing these files. Test portrait/landscape, navigation, tabs, dialogs, light/dark mode and horizontal overflow. A physical centimeter and apparent size depend on device scaling and browser zoom; the CSS frame gives consistent composition at equivalent browser settings.

The longer English cover headline uses a 40–48px size within the desktop frame, reserves room for the theme control, and starts below the index on short windows. The Portuguese headline also fits short windows, and all desktop cover indexes use 14px type with a minimum natural width to prevent cramped labels. English subsection headings share a 17px sans-serif hierarchy; body instructions remain 16px. Cover sunrise/sunset follows the forecast above the index rather than aligning to its final link.
