Lavavajillas

Cómo usar

  • Usa productos específicos para lavavajillas. No uses jabón de platos común ni detergente para ropa.
  • El equipo permanece apagado para evitar productos inadecuados. Ponte en contacto para que pueda activarlo a distancia.
  • Utiliza una pastilla para lavavajillas y abrillantador. Los ejemplos de las fotos son FINISH TABS y CIF Secante.
